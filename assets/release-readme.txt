轻映 {{VERSION}} · Windows x64 便携版

解压到同一文件夹后，双击 SimpleKeymap.exe。
请保留 SimpleKeymap.Input.exe，它是配套的隐藏输入服务。

点击「添加第一条映射」，按窗口提示选择实际要按的键、
它要代替的键，再确认效果。也可从「侧键 → 中键」示例开始。
点击「添加并启用」后切换到其他应用试按，轻映窗口内不改键。
按下与抬起完整跟随；Ctrl + Alt + F12 暂停 / 恢复。
最小化继续运行，关闭窗口停止映射并退出。

修改规则：点击该条旁的「修改」，点击「更换」调整按键，
再「保存修改」。取消或关闭保留原规则。
行左侧开关控制该条规则，右侧直接修改和删除，删除后可撤销。
「映射总开关」控制全部并保留各条选择。F2 修改，Delete 删除。
如提示更改未保存，请处理目录权限或文件占用后「重试保存」。

配置仅保存在本机 %APPDATA%/SimpleKeymap/config.json。
顶部「支持与反馈」直接打开官网对应区域。
「关于与许可」可查看使用说明、复制诊断信息及离线阅读 GPL。
「检查更新」提供手动检查、官网下载和「启动时检查更新」选项。
启动检查默认关闭；开启后仅检查并提示，下载和替换由用户操作。
