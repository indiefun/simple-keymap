轻映 {{VERSION}} · Windows x64 便携版

将 ZIP 全部解压到同一文件夹，双击 SimpleKeymap.exe。
请保留配套的 SimpleKeymap.Input.exe，无需单独打开。

点击「添加第一条映射」，按窗口提示选择实际要按的键、
它要代替的键，再确认效果。也可从「侧键 → 中键」示例开始。
点击「添加并启用」后切换到其他应用试按，轻映窗口内不改键。
操作结果和保存错误显示在左下角状态栏。
按下与抬起完整跟随；Ctrl + Alt + F12 暂停 / 恢复。
最小化继续运行，关闭窗口停止映射并退出。

行左侧开关控制单条映射，右侧可修改、删除，删除后可撤销。
「映射总开关」控制全部映射并保留各条选择。
如提示未保存，请处理文件夹权限或文件占用后「重试保存」。

配置保存到软件同目录的 config.json，复制整个文件夹即可迁移。
请放在可写目录，首次启动自动创建配置。
升级前关闭旧版，完整解压新版并保留 config.json；
换用新文件夹时也请一并复制它。发布包不含用户配置。
顶部「支持与反馈」直接打开官网对应区域。
「关于与许可」可查看使用说明、复制诊断信息及离线阅读 GPL。
「检查更新」可手动检查或前往官网下载。
启动时检查默认关闭，开启后提示新版，下载和替换由用户操作。
