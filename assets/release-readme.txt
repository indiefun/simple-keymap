轻映 {{VERSION}} · Windows x64 便携版

解压到同一文件夹后，双击 SimpleKeymap.exe。
请保留 SimpleKeymap.Input.exe，它是配套的隐藏输入服务。

默认已选择「鼠标侧键 1 → 鼠标中键」，点击「添加映射」，
再切换到其他应用试按。轻映自己的配置窗口内暂不执行映射。
按下与抬起完整跟随；Ctrl + Alt + F12 暂停 / 恢复。
最小化继续运行，关闭窗口停止映射并退出。

配置仅保存在本机 %APPDATA%/SimpleKeymap/config.json。
点击程序右上角「支持与反馈」，会打开官网并定位到支持区域。
