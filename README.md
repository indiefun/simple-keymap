# 轻映 · 简单按键映射器

Windows x64 桌面小工具，用 Go 和原生 Win32 编写。用一个键替代另一个键，无需安装驱动或系统服务。

## 使用

双击 **`dist/SimpleKeymap.exe`**。同目录的 `SimpleKeymap.Input.exe` 是隐藏的输入辅助进程，需要一起保留。所有打包文件统一在 `dist`。

1. 默认已选好「鼠标侧键 1（后退）→ 鼠标中键（滚轮按下）」，点击「添加映射」即可。
2. 列表左侧勾选框控制单条规则，选中一行后可删除。
3. 右上角控制全部映射；`Ctrl + Alt + F12` 全局暂停 / 恢复。
4. 可以从列表选择其他键，也可点击「录入」后实际按一下。Esc 取消录入，8 秒后自动取消。

映射完全跟随原按键的按下和抬起：

| 实际操作 | 模拟操作 |
| --- | --- |
| 按下侧键 1 | 按下鼠标中键 |
| 一直按住侧键 1 | 中键一直保持按下 |
| 抬起侧键 1 | 抬起鼠标中键 |
| 再次按下、抬起侧键 1 | 再次按下、抬起中键 |

不是切换开关，不是只发送按下，也不会在按下时自动补一个抬起。鼠标右键的按下 / 抬起不改变侧键到中键的映射。侧键原来的后退动作会被拦截；模拟输入不会递归触发另一条规则。

配置窗口内暂不执行映射，方便操作；切到其他程序后生效。最小化后继续映射，关闭窗口停止监听并退出。正常退出会丢弃积压操作，仅释放已经模拟按住的键。

配置自动保存到 `%APPDATA%/SimpleKeymap/config.json`。启动会恢复规则和总开关；配置读取失败时暂停，并保留原文件直到主动修改。

## 异常与退出

模拟输入只在独立辅助进程里发送，主程序不会回退为自己发送。缺少辅助文件或版本不匹配会提示退出。

发送和通信共用 750ms 超时。超时或发送失败后自动暂停，丢弃后续输出，不重试、不反复拉起辅助进程。主窗口可继续操作和关闭。关闭等待有时限；辅助进程绑定到主进程的 Windows Job，主进程被强制结束时也会请求结束辅助进程。

曾在本机发现 Windows `NtUserSendInput` 卡在内核中，连独立程序的零距离输入也被阻塞。这种情况可能导致一个辅助进程残留到重启，即使请求终止也无法立即清除；Go 程序不能保证恢复 Windows 内核。若出现「Windows 输入发送超时」，请保存工作并重启 Windows，不要反复开启映射。

## 支持范围

- 鼠标左键、右键、中键、侧键 1 / 2。
- 字母、数字、F1–F12、常用编辑键、方向键、左右 Ctrl / Shift / Alt、常用符号、小键盘、媒体键。
- 仅单个键到单个键；没有组合键、宏、连点、滚轮滚动或应用专属规则。
- 鼠标驱动需要把侧键作为标准前进 / 后退按钮输出。
- 目标程序以管理员运行时，轻映需要相同权限。部分游戏或受保护程序可能不接受模拟输入。

## 编译

Windows x64，Go 1.23 或更新版本；无第三方 Go 依赖，不需要 C 编译器。

```powershell
.\build.ps1
```

脚本运行测试和 `go vet`，随后结束**本工程目录内**正在运行的轻映及输入辅助进程，重新生成 `dist` 内的两个 exe。不会结束其他目录里的同名程序。测试或构建失败会报错。Go 不在 PATH 时使用工程内 `.tools/go/bin/go.exe`。

仅检查、不打包、不结束正在使用的程序：

```powershell
.\build.ps1 -TestOnly
```

退出测试使用生产窗口消息循环和真实子进程，以受控输入替身模拟阻塞，不会向游戏或桌面发送按键。测试通过不等于已经验证《荒野大镖客 1》的兼容性。审查细节见 `REVIEW.md`。
