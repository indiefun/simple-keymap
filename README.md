# 轻映 · 简单按键映射器

免费开源的 Windows x64 改键工具，用一个键代替另一个键。解压即用，无需安装驱动或系统服务。

[官网](https://qingying.luming.host/) · [下载最新版](https://github.com/indiefun/simple-keymap/releases/latest) · [支持与反馈](https://qingying.luming.host/#support)

## 开始使用

1. 下载便携版 ZIP，**全部解压到同一文件夹**，双击 `SimpleKeymap.exe`。保留配套的 `SimpleKeymap.Input.exe`，无需单独打开。
2. 点击「添加第一条映射」，按引导选择**实际要按的键 → 要代替的键 → 确认效果**，也可从「侧键 → 中键」示例开始。
3. 点击「添加并启用」，切换到其他应用试按。例如，侧键代替中键时，按住侧键就持续按住中键，松开即释放。

主界面管理已有映射：行左侧开关控制单条规则，右侧可直接修改、删除；删除后可撤销。总开关控制全部映射，`Ctrl + Alt + F12` 随时暂停或恢复。

轻映窗口内暂停改键，便于操作。最小化后继续运行，关闭窗口停止映射并退出。保存结果和错误统一显示在左下角状态栏；如提示未保存，处理后点击「重试保存」。

## 配置与更新

配置自动保存到 **软件同目录的 `config.json`**。请将软件放在可写文件夹，复制整个文件夹即可迁移。

升级时先关闭旧版，将新版完整解压到原目录，**保留 `config.json`**；换用新目录时也请一并复制它。发布包不含用户配置。

顶部「检查更新」可手动检查和前往官网下载，也可开启「启动时检查更新」（默认关闭）。检查只提示新版本，下载和替换由用户操作。「关于与许可」提供使用说明、诊断信息和离线 GPL 全文。

## 支持范围

- 支持鼠标左键、右键、中键、侧键 1 / 2，以及常用键盘键、小键盘和媒体键；侧键需由鼠标驱动输出标准前进 / 后退按钮。
- 目前提供单键到单键映射，不含组合键、宏、连点、滚轮滚动或按应用切换规则。
- 目标应用以管理员身份运行时，轻映需要相同权限。部分游戏或受保护程序可能不接受模拟输入。

遇到问题，可在「关于与许可 → 诊断信息」复制诊断摘要，连同操作步骤和目标应用提交到 [Issues](https://github.com/indiefun/simple-keymap/issues)，或前往[官网支持区](https://qingying.luming.host/#support)。诊断摘要不含按键记录和规则明细。若提示 Windows 输入发送超时，请保存工作并重启 Windows。

## 开发与维护

桌面程序使用 Go 和原生 Win32，无第三方 Go 依赖。Windows x64 安装 Go 1.23 或更新版本后，在仓库根目录执行：

```powershell
.\build.ps1
```

程序及便携包输出到 `dist/`。其他维护说明：
